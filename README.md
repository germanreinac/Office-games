# Office-games

## Restructured — an isometric office roguelite

The boss is forty feet tall, and corporate's restructuring has divided him into 30 cubes
scattered across the office. Each procedurally generated floor hides six: two inside furniture
(they twinkle, and a staple knocks them out), two carried by coworkers, one lying around, and one
held by the floor's mini-boss. Beating the mini-boss opens the elevator; cubes you leave behind stay
missing from the rebuilt boss unless you find them in overtime (endless mode).

**Play:** open `index.html` in a browser (no build step, no dependencies), or serve the folder
with any static host such as GitHub Pages.

**Controls:** WASD / arrows to move · mouse to aim, hold click to throw staples ·
Space for a chair roll (dodge) · M to mute. On touch: left thumb moves, right thumb aims and fires.

Everything (art, levels, sound) is generated in `game.js`.
